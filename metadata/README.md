# metadata/

VFB-loadable dataset **metadata** OWL, aggregated across all projects — one
`vfb_scRNAseq_metadata_<project>.owl` per dataset (RDF/XML). These are the files
VFB picks up directly; there is no need to hunt through per-project folders.

Generated by `scripts/build_rdf.py --project <p>` (writes here automatically).
Per-project intermediates (`<accession>.ttl` flat RDF, `<accession>.ofn`
functional syntax) stay under `projects/<p>/`.
