# Tm5ab

*Cluster `Tm5ab` (author class 104, one cluster per stage in the supervised annotation; cells per stage: P15 120, P30 115, P40 73, P50 121, P70 167, adult 404; stages P15, P30, P40, P50, P70, adult) in Ozel et al. 2021 (GEO GSE142787). Female Canton-S optic lobe scRNAseq, pupal time given as % pupal development at 25 C.*

## Summary
Transmedullary neuron cluster Tm5a plus Tm5b (Tm5ab), identified by a clear transcriptome match.

## Markers
The paper's text does not list specific marker genes for this type; the authors identified it by correlation of its adult transcriptome with isolated-population transcriptomes (Methods, Extended Data Fig. 3), and a neural-network classifier propagated the identity across stages.

## Location
Optic lobe: medulla to lobula (transmedullary).

## Function
Visual system columnar neuron; the paper does not discuss function.

## Label provenance
Label assigned by the authors by transcriptome match. The name denotes the two subtypes Tm5a and Tm5b together. Source: Supplementary Table 1, row 104. Adult annotation comment: "Clear match to Tm5ab transcriptome (Extended data Fig.3)." Pupal annotation comment: "P40: we kept only the 75% of class 104 cells belonging to a single unsupervised cluster."

## Mapping notes
Grouped call: Tm5a and Tm5b together (common parent Tm5 neurons); not a single type. P15, P30 and P40 cells are developing (immature) neurons, still wiring; P50 and P70 are pharate-adult stages (P70 = late pupa) and the adult sample is 1-3-day-old adult. The authors report that neuronal transcriptomes converge on those of older cells of the same type within ~15 h of birth, so type identity is already recognisable at P15.
