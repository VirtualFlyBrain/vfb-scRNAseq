# LPLC2

*Cluster `LPLC2` (author class 150, one cluster per stage in the supervised annotation; cells per stage: P15 29, P30 78, P40 54, P50 60, P70 70, adult 151; stages P15, P30, P40, P50, P70, adult) in Ozel et al. 2021 (GEO GSE142787). Female Canton-S optic lobe scRNAseq, pupal time given as % pupal development at 25 C.*

## Summary
Lobula plate/lobula columnar neuron type LPLC2, identified by the authors from a clear transcriptome match. Pupal stages are partial: the table notes only subsets of class cells fell in a single unsupervised cluster (see comment).

## Markers
The paper's text does not list specific marker genes for this type; the authors identified it by correlation of its adult transcriptome with isolated-population transcriptomes (Methods, Extended Data Fig. 3), and a neural-network classifier propagated the identity across stages.

## Location
Optic lobe: lobula plate and lobula (LPLC = lobula plate-lobula columnar neurons).

## Function
Visual feature-detecting columnar output neuron of the optic lobe; the paper does not discuss function.

## Label provenance
Label assigned by the authors by transcriptome match. Source: Supplementary Table 1, row 150. Adult annotation comment: "Clear match to LPLC2 transcriptome (Extended data Fig.3)." Pupal annotation comment: "P50: only 62% of class 149 cells belonged to a single unsupervised cluster. P30: only 66% of class 149 cells belonged to a single unsupervised cluster. P15: we kept only the 41% of class 150 cells belonging to a single unsupervised cluster."

## Mapping notes
Single, classic type (LPLC2), one author cluster. P15, P30 and P40 cells are developing (immature) neurons, still wiring; P50 and P70 are pharate-adult stages (P70 = late pupa) and the adult sample is 1-3-day-old adult. The authors report that neuronal transcriptomes converge on those of older cells of the same type within ~15 h of birth, so type identity is already recognisable at P15.
