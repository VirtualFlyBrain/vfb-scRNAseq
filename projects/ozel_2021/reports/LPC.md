# LPC

*Type `LPC` (Supplementary Table 1 cluster 257; P15 213 cells) in Özel et al. 2021 (Nature; GSE142787). Female Canton-S optic lobe, pupal stage only; the type is found only at P15.*

## Summary
Lamina precursor cells (LPCs) at P15, the progenitors that are progressively converted into lamina monopolar neurons.

## Markers
Supplementary Table 1: expresses gcm2, gcm, eya, so and upd --> lamina precursor cells, with maybe some committed glial precursor cells (citing Chotard and Salecker, 2007; Pineiro et al., 2014; Yasugi et al., 2008). Expresses lowly dpn --> might contain some neuroblasts (Extended Data Fig. 9, green circles).

## Location
Lateral OPC: the paper states that LPCs are progressively converted into lamina monopolar neurons (ref. 34). On UMAP the lamina monopolar clusters L1-L4 converge specifically towards the LPC cluster (Fig. 3a).

## Function
Progenitor state feeding lamina neuron production; the authors flag possible admixture of committed glial precursors and a few neuroblasts.

## Label provenance
Label and comment come from the authors' Supplementary Table 1 (cluster 257, name `LPC`). The label is the authors' final identity; no disagreement between sources was found. Supplementary Table 1 comment: "P15 unsupervised cluster 120. Expresses gcm2, gcm, eya, so and upd --> lamina precursor cells, with maybe some committed glial precursor cells (Chotard and Salecker, 2007; Pineiro et al., 2014; Yasugi et al., 2008). ## Mapping notes
Single type call: lamina precursor cell (optic lobe progenitor; P15 pupa), with the authors' caveat that it may include some glial precursors and neuroblasts.
