# T4/T5

*Cluster `T4/T5` (Seurat res-2.0 cluster 24; 648 cells; ages 0-30 days) in
Davie et al. 2018 (GSE107451, 57K adult brain). Merged label spanning the
classical T4 and T5 direction-selective motion neuron families.*

## Summary

T4/T5 is an author-merged identity for the well-known direction-selective
motion-detecting neurons of the fly optic lobe. Both T4 and T5 comprise four
anatomically and functionally distinct subtypes (a-d) that this
transcriptomic resolution cannot separate.

## Markers

Table S2 annotation "T4/T5" (method: mapping; refs Konstantinides et al.,
2018; Pankova and Borst, 2016). Top Table S3 markers for res-2.0 cluster 24:
CG14340, SoxN, CG42750, CNMaR, acj6, Drgx, Lim1, ST6Gal, Ten-a, zld, Fas3,
Sox102F, fkh, CG3655, Frq1. These are consistent with a shared
motion-detection columnar-neuron transcriptional program rather than
subtype-specific markers.

## Location

T4 dendrites lie in the proximal medulla (layer M10) receiving ON-pathway
input; T5 dendrites lie in the lobula (layer Lo1) receiving OFF-pathway
input. Both cell types send axons to the lobula plate, with the four
subtypes of each terminating in one of its four layers, encoding the four
cardinal directions of motion (Maisak et al., 2013).

## Function

T4/T5 neurons are the core direction-selective elements of the fly optomotor
/ motion-vision circuit: T4 for ON (brightness increment) motion, T5 for OFF
(brightness decrement) motion, each split into four subtypes tuned to one of
four cardinal directions.

## Label provenance

Table S2 and GEO agree: both annotate res-2.0 cluster 24 as the merged "T4/T5"
identity (label_validation.tsv: "match"). No REVIEW flag.

## Mapping notes

This is a genuine merged group at multiple levels: T4 and T5 are two
anatomically distinct cell types (different input layers, different
pathways), and each further comprises four subtypes (a-d) by lobula-plate
layer/direction tuning — none of which is resolved here. The honest FBbt
level is a common parent covering both T4 and T5 (e.g., an
"T4/T5 direction-selective neuron" grouping term), not any single subtype.
