# C2

*Cluster `C2` (Seurat res-2.0 cluster 77; 127 cells; ages 0-50 days) in Davie
et al. 2018 (GSE107451, 57K adult brain). GEO-labelled "C2" for a res-2.0
cluster that Table S2 leaves entirely unannotated — a naming not directly
supported by the paper's own tables.*

## Summary

C2 is one of a small set of centrifugal neuron types of the optic lobe
(alongside C3) that project retrogradely from the medulla back to the
lamina, providing feedback into early visual processing (established
Drosophila optic-lobe cell type; Fischbach and Dittrich, 1989). In this
atlas, however, the GEO "C2" label is attached to res-2.0 cluster 77, which
Table S2 records as "Unannotated" — i.e. the paper itself did not assign
this cluster a cell-type call; the C2 identity comes from the GEO
submission's own labelling, not from the published annotation table.

## Markers

- Table S3 top markers for res-2.0 cluster 77: bi, shakB, NaCP60E,
  Octbeta1R, CG14989, CG45049, nAChRalpha7, CG2016, CG15394, CG13698,
  RapGAP1, Gad1, Tsp97E, ort, Ets65A, Ggamma30A, Slob, Bx, Appl, Pka-C3.
- Gad1 (GABAergic marker) and ort (histamine receptor, marking cells
  postsynaptic to photoreceptors) are both present, consistent with an
  optic-lobe interneuron receiving photoreceptor-linked input, but neither
  is specific enough on its own to confirm a C2 identity.
- This marker list overlaps substantially with that of the "C3" cluster
  (res-2.0 cluster 65; see C3.md), sharing Octbeta1R, CG14989, Ets65A,
  Tsp97E, CG13698, Pka-C3, Ggamma30A, Bx — consistent with C2 and C3 being
  closely related sister centrifugal types, but not distinguishing them.

## Location

- **Neuropil:** if the C2 identity is correct, arborises in the medulla and
  projects centrifugally to the lamina, in a columnar (per-cartridge)
  pattern.
- **Cell class:** optic-lobe centrifugal columnar interneuron (class N),
  identity unconfirmed by the paper's own annotation.

## Function

- If correctly identified as C2: GABAergic centrifugal feedback from the
  medulla to the lamina (by analogy with the well-characterised C2 cell
  type; Fischbach and Dittrich, 1989); Gad1 expression in this cluster is
  at least consistent with a GABAergic identity.

## Label provenance

Table S2 res-2.0 cluster 77 is "Unannotated" (no method, no references).
label_validation.tsv flags this as "named in GEO; S2 res-2.0 Unannotated —
REVIEW": the GEO submitter's "C2" label is not backed by the paper's Table
S2 annotation. This is a genuine discrepancy, not a synonym or refinement.

## Mapping notes

Treat this as an uncertain/possible-state-or-type call rather than a
confirmed single cell type. The GEO label "C2" implies the classical
centrifugal neuron C2, and the marker profile (Gad1, ort, and overlap with
the "C3" cluster's markers) is not inconsistent with that, but the paper
itself never made this call — there is no Table S2 support, method or
reference. Flag high uncertainty for the mapping step: this may be C2, may
be a different unannotated optic-lobe interneuron, and its marker overlap
with the adjacent "C3" cluster suggests either genuine C2/C3 relatedness or
imperfect cluster separation at res-2.0.
