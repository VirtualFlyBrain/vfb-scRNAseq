# L4/L5

*Cluster `L4/L5` (Seurat res-2.0 cluster 20; 163 cells; ages 0-50 days) in
Davie et al. 2018 (GSE107451, 57K adult brain). Subcluster of the merged
L1/L2/L3/L4/L5 lamina-monopolar cluster, resolved as a joint L4+L5
population by the marker bsh.*

## Summary

L4 and L5 are two further lamina monopolar interneuron types. L4 is a
laterally-projecting columnar neuron that connects neighbouring lamina
cartridges, contributing to motion-detection circuitry; L5 relays lamina
output to the medulla and receives centrifugal feedback from medullary
neurons. The paper subclustered the merged res-2.0 cluster 20 ("L1/L2/L3/
L4/L5", regression-mapped to Tan et al. (2015)) and identified this
subcluster jointly for L4 and L5 using the shared marker bsh
(Hasegawa et al., 2013), rather than resolving the two types separately
(paper main text, Figure 2E-F).

## Markers

- bsh (brain-specific homeobox) — the marker used by the authors to call
  this subcluster jointly as L4/L5 (Hasegawa et al., 2013).
- The Table S3 top markers listed for this cluster (CG18598, CG11000, Rbp6,
  shakB, Teh2, CG14509, CG42392, CG10947, CG9813, scro, CG31345, glob1, slp1,
  pdm3, AstA-R1, cpx, CG32647, slp2, para, CR45621) are for the **parent**
  res-2.0 cluster 20 (the pooled L1-L5 population), not specific to the
  L4/L5 subcluster.

## Location

- **Cell class:** lamina monopolar columnar interneurons (class N).
- **Soma/dendrites:** lamina cortex and cartridges; **axons:** L4 projects
  laterally within the lamina/proximal medulla to neighbouring cartridges,
  L5 projects to the medulla alongside L1/L2.

## Function

- L4 provides lateral (inter-cartridge) connections supporting directional
  motion detection; L5 relays lamina signal to the medulla and integrates
  centrifugal feedback. Both are downstream of outer photoreceptor
  (R1-R6) input via the lamina cartridge.

## Label provenance

Table S2 res-2.0 cluster 20 is annotated "L1/L2/L3/L4/L5" (method: mapping,
ref: Tan et al., 2015) — a merged pool, not subtype-resolved at res-2.0. The
GEO "L4/L5" label corresponds to a subcluster of this pool identified in the
paper's Figure 2E/F subclustering, using the marker bsh (Hasegawa et al.,
2013; Tan et al., 2015); label_validation.tsv records this as
"subcluster/res-8.0 of S2 res-2.0 'L1/L2/L3/L4/L5'", no REVIEW flag.

## Mapping notes

Unlike L1/L2/L3, this GEO label is itself a merged group of two distinct,
well-established cell types (L4 and L5), resolved together by a marker
(bsh) shared between them rather than split further. The honest mapping
level is therefore a common parent grouping "L4 and L5 lamina monopolar
neurons," not either type individually — flag for the mapping step that a
single exact-match FBbt term for L4 or for L5 alone would over-claim
resolution this cluster does not have. Marker evidence in hand (Table S3) is
for the undifferentiated parent cluster 20, not specific to L4/L5.
