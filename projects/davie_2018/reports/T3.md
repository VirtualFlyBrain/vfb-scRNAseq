# T3

*Cluster `T3` (Seurat res-2.0 cluster 33; 471 cells; ages 0-50 days) in Davie
et al. 2018 (GSE107451, 57K adult brain). GEO-only name; Table S2 leaves this
res-2.0 cluster unannotated.*

## Summary

T3 is a GEO label for res-2.0 cluster 33, which Table S2 itself lists as
"Unannotated" (no method, no references). The GEO curators apparently
assigned "T3" post hoc, likely by analogy with the neighbouring merged
"T2/T3" identity carried by cluster 31 (this atlas's separate GEO "T2"
label), but there is no author-attributed marker/mapping evidence in the
supplementary tables specifically supporting T3 for cluster 33.

## Markers

Top Table S3 markers for res-2.0 cluster 33: beat-IIa, Tk, acj6, beat-IIb,
nAChRalpha7, Con, Calx, Drep3, NetA, fkh, sgg, bi, Cbp53E, CG42541, CG13698,
CG2082, ST6Gal. Overlap with cluster 31 (Tk, acj6, Cbp53E, beat-family genes)
supports a related optic-lobe identity to T2, but with a distinct beat
paralog subset (beat-IIa/IIb vs beat-Ia/Ib/Ic), consistent with two related
but separable transcriptional clusters.

## Location

Presumed optic-lobe columnar/tangential neuron by analogy to T2, per
classical T-neuron nomenclature (Fischbach and Dittrich, 1989); no
independent anatomical evidence given for this specific cluster in the
paper.

## Function

Not characterized in the atlas; no functional data given for this cluster.

## Label provenance

REVIEW: Table S2 gives cluster 33 no annotation, method, or references
("Unannotated"). The GEO label "T3" therefore rests on curatorial inference
(pairing with the "T2/T3" annotation Table S2 gives to the neighbouring
cluster 31), not on evidence in the supplementary tables for cluster 33
itself (label_validation.tsv: "named in GEO; S2 res-2.0 Unannotated —
REVIEW").

## Mapping notes

This is the weakest-evidenced cluster of the T2/T3 pair. Treat "T3" as a
provisional/curatorial label rather than an author-confirmed identity;
mapping should either go to a conservative parent term shared with T2, or be
flagged for the FBbt-mapping step as evidence-poor rather than committed to a
specific T3 exact match.
