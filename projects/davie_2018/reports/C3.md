# C3

*Cluster `C3` (Seurat res-2.0 cluster 65; 219 cells; ages 0-50 days) in Davie
et al. 2018 (GSE107451, 57K adult brain). GEO-labelled "C3" for a res-2.0
cluster the paper's Table S2 calls the merged pair "C2/C3".*

## Summary

C3 is one of a small set of centrifugal neuron types of the optic lobe
(alongside C2) that project retrogradely from the medulla back to the
lamina, providing feedback into early visual processing (established
Drosophila optic-lobe cell type; Fischbach and Dittrich, 1989). The paper
identified res-2.0 cluster 65 as a merged "C2/C3" population by literature
markers (Kolodziejczyk et al., 2008; Konstantinides et al., 2018), without
separating the two types; the GEO submission narrows this to the single
label "C3" for this cluster, while assigning "C2" to a different,
Unannotated res-2.0 cluster (77; see C2.md).

## Markers

- Table S3 top markers for res-2.0 cluster 65: Octbeta1R, CG14989, Nos,
  Gad1, Ets65A, hbn, CG10089, CG13698, CG9896, Pka-C3, Pvf3, Dll, Bx, NijC,
  beat-VII, GluRIB, cpx, Eip63F-1, Tsp97E, CG33639.
- Gad1 (GABAergic marker) is present, consistent with the GABAergic
  centrifugal C2/C-type identity reported for this optic-lobe neuron class
  in the wider literature.
- These markers were used by the authors only to call the combined
  "C2/C3" identity, not to split the two types; the marker list overlaps
  substantially with that of the separately GEO-labelled "C2" cluster
  (res-2.0 cluster 77), sharing Octbeta1R, CG14989, Ets65A, Tsp97E,
  CG13698, Pka-C3.

## Location

- **Neuropil:** medulla, with centrifugal projections to the lamina, in a
  columnar (per-cartridge) pattern.
- **Cell class:** optic-lobe centrifugal columnar interneuron(s) (class N).

## Function

- Centrifugal feedback from the medulla to the lamina; Gad1 expression is
  consistent with GABAergic neurotransmission, as reported for centrifugal
  C-type neurons generally.

## Label provenance

Table S2 res-2.0 cluster 65 is annotated "C2/C3" (method: literature
markers; refs: Kolodziejczyk et al., 2008; Konstantinides et al., 2018) — a
merged call covering both centrifugal types. label_validation.tsv flags the
GEO "C3" label for this cluster as "differs from S2 res-2.0 'C2/C3' —
REVIEW": the GEO submitter narrowed the paper's merged pair to "C3" alone
for this cluster, while separately (and without S2 support) labelling a
different, Unannotated cluster (77) as "C2". This narrowing to a single
subtype is not evidenced in the paper text or Table S2.

## Mapping notes

The evidence supports a merged group ("C2 and/or C3 centrifugal neurons"),
not a confirmed single C3 identity: Table S2 calls this cluster "C2/C3"
without further resolution, and the GEO split into separate C2 (cluster 77)
and C3 (cluster 65) labels is not paper-supported. The honest mapping level
is therefore a common parent term covering both C2 and C3 centrifugal
neurons, or — if FBbt requires a single-type call — flag this cluster as
possibly C3 but with real risk it instead represents the unresolved C2/C3
pair. Cross-reference C2.md, whose marker profile overlaps with this
cluster's.
