# L1

*Cluster `L1` (Seurat res-2.0 cluster 20; 84 cells; ages 0-50 days) in Davie
et al. 2018 (GSE107451, 57K adult brain). Subcluster of the merged
L1/L2/L3/L4/L5 lamina-monopolar cluster, resolved to L1 by marker mapping.*

## Summary

L1 is lamina monopolar neuron 1, a columnar interneuron of the lamina that
carries the principal input to the ON-motion pathway of the optic lobe. The
paper subclustered the merged res-2.0 cluster 20 (307 cells labelled
"L1/L2/L3/L4/L5" by regression-model mapping to Tan et al. (2015) bulk
transcriptomes) and, using known markers, resolved a subcluster expressing
VGlut as L1 (Kolodziejczyk et al., 2008), alongside a separately resolved
L4/L5 subcluster (bsh) and regression-model matches for L2 and L3 (paper
main text, Figure 2E-F).

## Markers

- VGlut (glutamatergic) expression was the marker used by the authors to
  identify this subcluster as L1 (Kolodziejczyk et al., 2008).
- The Table S3 top markers listed for this cluster (CG18598, CG11000, Rbp6,
  shakB, Teh2, CG14509, CG42392, CG10947, CG9813, scro, CG31345, glob1, slp1,
  pdm3, AstA-R1, cpx, CG32647, slp2, para, CR45621) are for the **parent**
  res-2.0 cluster 20 (the pooled L1-L5 population) prior to subclustering,
  not specific to the L1 subcluster.

## Location

- **Cell class:** lamina monopolar columnar interneuron (class N).
- **Soma/dendrites:** lamina cortex and cartridges; **axon:** projects to the
  medulla, terminating in the ON-pathway input layers (synapsing onto Mi1
  and other ON-pathway targets).

## Function

- Receives histaminergic input from outer photoreceptors R1-R6 in the lamina
  cartridge and relays it to the medulla as the primary ON-pathway
  interneuron; glutamatergic (VGlut+).

## Label provenance

Table S2 res-2.0 cluster 20 is annotated "L1/L2/L3/L4/L5" (method: mapping,
ref: Tan et al., 2015) — a merged pool, not yet subtype-resolved at res-2.0.
The GEO "L1" label corresponds to a subcluster of this pool identified in the
paper's Figure 2E/F subclustering analysis using the literature marker VGlut
(Kolodziejczyk et al., 2008; Tan et al., 2015); label_validation.tsv records
this as "subcluster/res-8.0 of S2 res-2.0 'L1/L2/L3/L4/L5'", no REVIEW flag.

## Mapping notes

L1 is a well-established, singular Drosophila cell type; an adult-specific
FBbt term for "lamina monopolar neuron L1" is expected and this cluster
should map to it exactly. Caveat: the marker-gene evidence available
(Table S3) is for the undifferentiated parent cluster, not L1-specific — the
L1 call rests on the paper's VGlut-based subclustering rather than on markers
unique to this report.
