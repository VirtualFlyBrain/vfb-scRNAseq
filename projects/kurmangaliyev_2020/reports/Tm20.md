# Tm20

*Cluster `Tm20` (subtype == type `Tm20`, class N) in Kurmangaliyev et al. 2020
(GSE156455). One of the 13 medulla neurons profiled with connectome data
(Figure S11). Anatomy is established; dataset context from the atlas paper.*

## Summary

Tm20 is a narrow-field transmedullary columnar neuron of the adult optic lobe.
It receives dendritic input in medulla layers M1-M3 (primarily from lamina
monopolar neuron L3 and photoreceptor R8) and projects its axon across the
second optic chiasma to terminate with presynaptic arbors in lobula layer 5,
where it provides strong input to lobula intrinsic neuron Li4. It is among the
largest transcriptional clusters in the atlas, consistent with its unicolumnar
organisation (approximately one cell per optic column).

## Markers

- Profiled among the 13 medulla neurons with mapped connectome data in the atlas
  (Figure S11; connectivity adapted from Takemura et al., 2015).
- Identity confirmed by correlation with the reference connectome dataset and by
  known cell-type-specific marker genes (Kurmangaliyev et al., 2020, Figure S5C).

## Location

- **Cell class:** narrow-field transmedullary (Tm) columnar neuron; class N
  (neuron) in the atlas.
- **Dendrites:** medulla layers M1-M3 (input zone).
- **Axon terminal:** lobula layer 5 (output zone).
- **Organisation:** unicolumnar; one cell per optic column.

## Function

- Cholinergic; relays colour/luminance information from medulla to lobula.
- Receives GABAergic input from L3 and R8 photoreceptor input in medulla;
  outputs strongly onto Li4 in lobula layer 5.
