# Lpi3.4

*Cell-type report for cluster `Lpi3.4` (subtype; type `Lpi3-4`, class N -- neuron)
in Kurmangaliyev et al. 2020, Drosophila visual system developmental atlas
(GSE156455, DOI 10.1016/j.neuron.2020.10.006). Evidence from established
optic-lobe anatomy (Mauss et al., 2015; Shinomiya et al., 2019, 2022).*

## Summary

Lpi3.4 is the cluster label used in the Kurmangaliyev 2020 atlas for the lobula
plate intrinsic neuron type commonly denoted LPi3-4 in the anatomical literature.
It is an adult optic lobe interneuron intrinsic to the lobula plate. Its soma
resides in the cell body rind of the medulla; a primary neurite traverses the
medulla from distal to proximal, crosses the second optic chiasm, and terminates
in the lobula plate. It receives input (postsynaptic arbor) in lobula plate
**layer 3** and provides output (presynaptic arbor) in lobula plate **layer 4**,
making it a layer-spanning feedback neuron within the lobula plate. It is
glutamatergic.

## Markers

- The cluster is named by its layer connectivity signature (layers 3 and 4),
  following the anatomical LPi3-4 nomenclature.
- LPi3-4 neurons are **glutamatergic** (Mauss et al., 2015).
- They receive their primary input from T4c and T5c neurons (Shinomiya et al.,
  2022), the same two cell types that arborise in lobula plate layer 3.

## Location

- **Soma:** cell body rind of the medulla.
- **Primary neurite:** runs from distal to proximal medulla, then crosses the
  second optic chiasm.
- **Dendrites (input):** lobula plate layer 3.
- **Axon terminals (output):** lobula plate layer 4.

## Function

- LPi3-4 is a lobula plate intrinsic interneuron that mediates cross-layer
  interaction within the lobula plate, receiving direction-selective input
  (predominantly from T4c and T5c neurons in layer 3) and providing inhibitory or
  modulatory output into layer 4.
- Together with related LPi types (LPi1-2, LPi2-1, LPi4-3), these neurons are
  thought to contribute to direction-selectivity computation within the lobula
  plate network.

## Mapping notes

- FBbt contains an exact term for this type: FBbt:00111289
  "lobula plate intrinsic neuron LPi3-4", defined as a lobula plate intrinsic
  neuron with soma in the medulla cell body rind, presynaptic terminals in layer 4,
  and postsynaptic dendrites in layer 3, that is glutamatergic (Mauss et al., 2015;
  Shinomiya et al., 2019). The label and biology match the cluster precisely.
- Parent term: lobula plate intrinsic neuron (FBbt:00003910).
- The 2024 Matsliah nomenclature note in the FBbt definition records an alternative
  name unrelated to layer innervation; this does not affect the match.
