# N1

*Cluster `N1` (subtype == type `N1`, class N — neuron) in Kurmangaliyev et al.
2020 (GSE156455). A numbered cluster, NOT matched to a named optic-lobe type.*

## Summary

N1 is a **numbered transcriptional cluster** of the main atlas, assigned to cell
class N (neuron) but **not matched to a named/known optic-lobe cell type**. The
authors used numbered labels (N1, N19, ...) for clusters whose anatomical identity
they did not resolve. N1 therefore represents an optic-lobe neuron of **unresolved
type**, defined only transcriptomically.

## Markers

- None established for an anatomical identity; the cluster is defined by its
  transcriptional profile, not a known marker/cell-type correspondence.

## Location

- **Cell class:** optic-lobe neuron (class N). Specific neuropil / morphological
  type unresolved.

## Function

- Unresolved.

## Mapping notes

- No specific FBbt anatomical type is expected to correspond. At most a **broad
  match** to a high-level term (e.g. adult optic lobe neuron / neuron) is
  defensible; more likely **no confident match**.
- This is an **unidentified transcriptomic cluster, not a characterised new cell
  type** — so it is **NOT** a candidate for an FBbt new-term request. Set
  `new_term_needed` false and recommend leaving unmapped (or broad) pending
  identity resolution.
