# Mi1

*Cluster `Mi1` (subtype == type `Mi1`, class N) in Kurmangaliyev et al. 2020
(GSE156455). One of the 13 medulla neurons profiled with connectome data
(Figure S11). Anatomy is established; dataset context from the atlas paper.*

## Summary

Mi1 is a medulla intrinsic neuron — a columnar cell intrinsic to the medulla and
a core relay of the ON motion-detection pathway. It receives input from lamina
monopolar neuron L1 and is a major presynaptic input onto T4 dendrites in medulla
layer M10.

## Markers

- Bsh (Brain-specific homeobox) is an established marker of Mi1 (and a subset of
  Bsh+ medulla neurons).
- Profiled in the atlas among 13 medulla neurons with mapped connectivity
  (Figure S11; connectome adapted from Takemura et al., 2015).

## Location

- **Cell class:** medulla intrinsic columnar neuron (class N).
- **Arborisations:** medulla layers (approximately M1, M5, M9/M10).

## Function

- Cholinergic; relays the L1 (ON) signal onto T4, central to ON-pathway motion
  detection.
