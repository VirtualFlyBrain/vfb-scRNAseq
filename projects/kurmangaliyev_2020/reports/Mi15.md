# Mi15

*Cluster `Mi15` (type `Mi15`, class N=neuron) in Kurmangaliyev et al. 2020
(GSE156455). Mi15 is an established optic-lobe cell type defined by classical
morphology and confirmed by scRNAseq.*

## Summary

Mi15 is a medulla intrinsic unicolumnar interneuron of the adult optic lobe.
Its primary neurite splits in medulla layer M1 and sends vertical branches as
far as layer M7. A separate process extends from the distal medulla into the
first optic chiasma, where it receives approximately half of its photoreceptor
input; in central columns this input is selective for R8 rather than R7
photoreceptors, though selectivity is lost in the dorsal rim area. Mi15 is
both cholinergic and dopaminergic, and is a Notch OFF hemilineage secondary
neuron born from a medulla neuroblast.

## Markers

- Cluster is named directly after the canonical morphological type Mi15
  (Takemura et al., 2013; Takemura et al., 2015).
- Transcriptomic identity consistent with a cholinergic and dopaminergic
  medulla intrinsic columnar neuron.

## Location

- **Neuropil:** medulla (layers M1-M7) and first optic chiasma.
- **Cell body:** medulla cortex cell body rind.
- **Cell class:** optic lobe intrinsic unicolumnar neuron (narrow-field).

## Function

- Medulla interneuron; unicolumnar with R8-selective photoreceptor input via
  the first optic chiasma. Cholinergic and dopaminergic neurotransmission.
  Classified as an optic lobe narrow-field columnar neuron and a Notch OFF
  hemilineage secondary neuron.

## Mapping notes

- FBbt has a specific term "medulla intrinsic neuron Mi15" (FBbt:00111285)
  whose definition matches this cluster precisely: same unicolumnar morphology,
  same layer profile (M1-M7), same optic chiasma process with R8-selective
  input, same dual cholinergic/dopaminergic neurotransmitter identity, and same
  hemilineage classification. This is an exact match.
