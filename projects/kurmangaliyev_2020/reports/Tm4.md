# Tm4

*Cell-type report for cluster `Tm4` (type Tm4, class N — neuron)
in Kurmangaliyev et al. 2020, Drosophila visual system developmental atlas
(GSE156455, DOI 10.1016/j.neuron.2020.10.006). Evidence from established
optic-lobe anatomy (Fischbach and Dittrich, 1989; Takemura et al., 2013;
Shinomiya et al., 2014; Davis et al., 2020).*

## Summary

Tm4 is a narrow-field transmedullary neuron of the adult *Drosophila* optic lobe.
It arborizes in medulla layers M2, M3, M4 and M9 (fine arborizations) and M2, M4,
M9 (bleb-type), and terminates with bleb-type arborizations in lobula layers 1, 2
and 4, with fine arborizations in layer 3. It is a columnar neuron (one per optic
column) assigned to the Notch ON hemilineage of medulla neuroblasts. The cluster
label `Tm4` is the standard anatomical designation for this cell type.

## Markers

- Defined transcriptomically in the atlas as a distinct neuron subpopulation
  within the medulla/lobula transmedullary neuron series.
- Neurotransmitter identity: dual cholinergic and GABAergic (co-expresses
  *ChAT* / *VAChT* for acetylcholine and *VGAT* / anti-GABA labelling for GABA;
  Davis et al., 2020; Raghu et al., 2013).

## Location

- **Soma:** distal to the medulla (outer cortex).
- **Dendrites / fine arborizations:** medulla layers M2, M3, M4, M9.
- **Axon terminals:** lobula layers 1, 2, 3 (fine) and 4 (bleb-type).
- **Connectivity:** receives input in the medulla from lamina monopolar neuron L2
  and centrifugal neuron C3 (Takemura et al., 2013); outputs in lobula layer 1
  to T5 neurons (Shinomiya et al., 2014).

## Function

Tm4 is a visual interneuron of the OFF-channel transmedullary series, relaying
processed visual information from the medulla to the lobula. Its presynaptic
partner T5 (lobula layer 1) and its lamina input L2 place it in the OFF-motion
processing pathway.
