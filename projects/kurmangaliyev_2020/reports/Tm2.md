# Tm2

*Cluster `Tm2` (subtype == type `Tm2`, class N) in Kurmangaliyev et al. 2020
(GSE156455). One of the 13 medulla neurons profiled with connectome data
(Figure S11). Anatomy is established; dataset context from the atlas paper.*

## Summary

Tm2 is a narrow-field transmedullary columnar neuron of the adult optic lobe.
It receives dendritic input in the distal medulla (principally layer M2, with
arborizations also in M1 and M4) from lamina monopolar neuron L2, and projects
its axon across the second optic chiasma to terminate with presynaptic arbors in
lobula layer 2. It is a cholinergic neuron and is unicolumnar (approximately one
cell per optic column). Tm2 is a core component of the OFF motion-detection
pathway, relaying luminance-decrement signals from L2 in the medulla to the
lobula where it contributes input to lobula plate tangential cells via
interneurons.

## Markers

- Profiled among the 13 medulla neurons with mapped connectome data in the atlas
  (Figure S11; connectivity adapted from Takemura et al., 2013).
- Identity confirmed by correlation with the reference connectome dataset and by
  known cell-type-specific marker genes (Kurmangaliyev et al., 2020, Figure S5C).
- Cholinergic identity established by co-labelling with Cha-GAL4 and anti-ChAT
  antibody (Varija Raghu et al., 2011; Gao et al., 2008).

## Location

- **Cell class:** narrow-field transmedullary (Tm) columnar neuron; class N
  (neuron) in the atlas.
- **Cell body:** distal cortex of the medulla.
- **Dendrites:** medulla layers M1, M2, M4 (primary input zone M2).
- **Axon terminal:** lobula layer 2 (output zone).
- **Organisation:** unicolumnar; one cell per optic column.

## Function

- Cholinergic; relays luminance-decrement (OFF) information from lamina monopolar
  neuron L2 in the medulla to the lobula.
- Part of the OFF pathway contributing to motion vision; provides input in
  lobula layer 2 to downstream circuits.
