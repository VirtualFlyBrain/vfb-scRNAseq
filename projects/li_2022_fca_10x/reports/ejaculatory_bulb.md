# ejaculatory bulb

*Author type `ejaculatory bulb` in Li et al. 2022 (Fly Cell Atlas; 10x male reproductive glands 2185, 10x oenocyte 108; Smart-seq2 male reproductive glands 31, oenocyte 3; author term: FBbt:00004962 ejaculatory bulb). Largest male reproductive tract cluster, named for the organ.*

## Summary
A large cluster labelled with the organ name, ejaculatory bulb, with broad class gland. By the authors' context it would comprise the secretory columnar epithelial cells of the bulb wall, though a separate cluster, ejaculatory bulb epithelium, is also annotated in the same analysis, so the relationship between the two is unstated.

## Markers
No marker genes for this type are given in the supplementary text available here (figure S17 legend shows only the tSNE annotation); none are asserted.

## Location
Male reproductive glands analysis (2185 cells); 108 more 10x cells (and 3 Smart-seq2) fall in the oenocyte tissue analysis, presumably from co-dissected tissue (this is an observation, not an author explanation). Adult males.

## Function
The bulb wall is a thick columnar epithelium with intima enclosing a chamber of viscous fluid (FBbt definition of the structure); the paper provides no functional analysis of this cluster.

## Label provenance
Authors' ontology id FBbt:00004962 (ejaculatory bulb); broad class gland.

## Mapping notes
Organ-named label applied to cells; the call implies a cell group of the bulb (probably secretory epithelial cells) rather than the whole organ's composition. Distinct from the separately annotated bulb epithelium cluster. Adult.
