# ejaculatory bulb epithelium

*Author type `ejaculatory bulb epithelium` in Li et al. 2022 (Fly Cell Atlas; 10x male reproductive glands 670 cells; Smart-seq2 male reproductive glands 11 cells; author term: Manual Annotation). Epithelial cluster of the ejaculatory bulb, no FBbt term chosen by the authors.*

## Summary
Epithelial cells of the ejaculatory bulb, annotated by hand; broad class epithelial cell.

## Markers
No marker genes for this type are given in the supplementary text available here (figure S17 legend shows only the tSNE annotation); none are asserted.

## Location
Male reproductive glands analysis; adult males.

## Function
Epithelium forming the bulb wall; no function is described for this cluster in the paper.

## Label provenance
Authors' ontology id was Manual Annotation (no FBbt term assigned); broad class epithelial cell. A scripted label match finds a same-named epithelium class in FBbt, but that is not the authors' own choice.

## Mapping notes
Describes a single cell type defined by organ region (bulb epithelium). It coexists with a separate ejaculatory bulb cluster in the same tissue. Adult.
