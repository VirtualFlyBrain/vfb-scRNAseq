# expression/

VFB-loadable summary **expression** OWL, aggregated across all projects — one
`vfb_scRNAseq_expression_<project>.owl.gz` per dataset (gzipped RDF/XML). One
annotated `expresses` (RO:0002292) axiom per cluster × gene, carrying
`expression_level` (CPM mean over expressing cells), `expression_extent`
(fraction of expressing cells, filtered > cutoff), and `hide_in_terminfo`.

Generated by `scripts/build_expression.py --project <p>` (writes here
automatically). The diffable filtered table (`expression.tsv`, or `expression.tsv.gz` for large datasets), the per-cluster
report, and the counts JSON stay under `projects/<p>/`.
